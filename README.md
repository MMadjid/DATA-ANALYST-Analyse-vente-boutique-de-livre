# DATA-ANALYST-Analyse-vente-boutique-de-livre
Analyse vente boutique de livre
Analysez les ventes d'une librairie avec Python

Objectifs généraux : 

- Nettoyer et analyser des données de vente.

- Identifier des tendances de consommation.

- Étudier des liens entre caractéristiques clients et comportements d'achat.

- Présenter vos conclusions à l’aide de visualisations et de statistiques.


Questions principales à traiter : 

📊 1) Analyse des ventes

- Quel est le chiffre d'affaires global réalisé par la librairie ? OK

- Comment ce chiffre évolue-t-il au fil du temps (mois, trimestres, etc.) ? OK

- Quels sont les produits les plus vendus ? Les moins vendus ? ok

- Quelles sont les catégories de livres les plus rentables ? ok

🧍 2) Analyse des clients :

- Quels sont les profils types des clients (âge, genre, fréquence d'achat) ?

- Quelle est la relation entre l’âge et le panier moyen ?

- Les hommes et les femmes achètent-ils les mêmes types de livres ?

- Y a-t-il une corrélation entre âge et fréquence d'achat ?

- Peut-on identifier des groupes de clients selon leur comportement ?


V) Outils utilisés
- Langages : Python

- Bibliothèques :

Pour Python : pandas, numpy, matplotlib, seaborn, scipy.
